# Website Thương Mại Điện Tử

## Mô tả
Website thương mại điện tử đơn giản ,
có phân quyền người dùng gồm Admin, Seller và Buyer.

## Vai trò người dùng
- **Admin**: Quản lý người dùng, xem đơn hàng
- **Seller**: Quản lý sản phẩm
- **Buyer**: Xem sản phẩm, thêm vào giỏ hàng

## Chức năng chính
- Đăng ký / Đăng nhập
- Phân quyền Admin – Seller – Buyer
- Quản lý sản phẩm (thêm / sửa / xóa)
- Giỏ hàng (mô phỏng)

## Công nghệ sử dụng
- HTML, CSS, JavaScript
- PHP
- MySQL
- GitHub (làm việc nhóm)

## Cấu trúc thư mục
frontend/  : Giao diện người dùng  
backend/   : Xử lý logic & kết nối CSDL  
admin/     : Chức năng dành cho Admin  
seller/    : Chức năng dành cho Seller  
database/  : File SQL
